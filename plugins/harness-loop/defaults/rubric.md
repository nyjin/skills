# 판정 기준

## 관찰 판정

관찰 판정은 해당과 아님 두 값에 이유 한 줄이다. 중간 등급은 없다.

| 관찰 | 해당 조건 |
|---|---|
| 교정 | 사용자가 AI 가 이미 내린 판단이나 동작을 뒤집거나 바로잡았다. 새 요청·추가 지시는 아니다. 스킬 실행 중과 일반 작업 모두 본다 |
| 반복 실행 | 같은 목적의 명령·inline 스크립트를 다시 작성했다 |
| 실패·이탈 | 스킬 실행 중 도구가 실패했거나, AI 가 스킬이 정한 절차와 다르게 움직였다 |
| 승인용 질문 | AI 가 이미 결정해 놓고 승인만 남긴 질문이다: 대안 없는 "이대로 진행할까요?", 선택지가 진행·취소뿐이고 취소하면 다음 경로가 없음, 계획을 다 정한 뒤 "괜찮을까요?" |

승인용 질문은 질문 원문의 형태로 판정한다. 사용자가 긍정으로 답했다는 사실은 보조 근거다.

## 승인용 질문 제외

되돌리기 어렵거나 외부로 나가는 동작 앞의 확인은 승인용 질문이 아니다: push, 삭제, 메시지 전송, 티켓 생성, 배포.

## 모든 관찰 제외

| 제외 | 예 |
|---|---|
| 환경 원인 | 인증, 네트워크, 권한 프롬프트 |
| 바꿀 파일이 없는 것 | 말투, 응답 품질 |
| 정리 제안 | 메모리를 전역으로 옮기기 |

## 공통 확인

하나라도 아니면 결정 대상으로 올리지 않는다.

| 확인 | 기준 |
|---|---|
| 구체성 | 수정안에 이 스킬·프로젝트에만 있는 사실(경로, 명령, 이름, 순서)이 있다 |
| 실패 근거 | 이 규칙이 없어서(또는 틀려서) AI 가 실제로 다르게 움직인 장면을 근거 위치로 가리킬 수 있다 |

## 관찰 → 결정 대상

| 관찰 | 파일 검증 결과 | 결정 대상 |
|---|---|---|
| 교정(스킬 실행 중) | 지시가 없음 | 스킬 보완 |
| 교정(스킬 실행 중) | 지시가 틀렸거나 AI 가 지시를 무시함 | 지침·스크립트 수정 |
| 교정(일반 작업) | 적용되는 지침 파일 어디에도 규칙이 없음, 또는 메모리에만 있는데 재발함 | 지침 보완 |
| 교정(일반 작업) | 지침 파일에 규칙이 있는데 틀렸거나 AI 가 무시함 | 지침·스크립트 수정(대상이 지침 파일) |
| 반복 실행 | 담을 스크립트가 없음 | 스크립트화 |
| 반복 실행 | 스킬에 이미 스크립트가 있는데 쓰지 않음 | 지침·스크립트 수정 |
| 실패·이탈 | 원인이 지시·스크립트에 있음 | 지침·스크립트 수정 |
| 실패·이탈 | 원인이 환경에 있음 | 버림 |
| 승인용 질문 | 묻게 만든 지시 줄이 있음 | 지침·스크립트 수정 |
| 승인용 질문 | 지시 없이 AI 가 스스로 물음 | 스킬 보완("이 단계는 묻지 않는다") |
| 어떤 관찰이든 | 수정 이력 이후 버전에서 같은 문제 | 수정 방식 재검토 |
