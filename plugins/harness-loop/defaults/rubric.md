# 채점 기준

재발성은 스크립트가 같은 sig 가 나온 세션 수로 센다. judge 는 영향·해결 가능성의 1~3점과 근거를 낸다.

| 차원 | 1 | 2 | 3 |
|---|---|---|---|
| 재발성 | 1개 세션 | 2~3개 세션 | 4개 이상 세션 |
| 영향 | 낭비 거의 없음 | 우회나 재시도 | 막힘·틀린 결과·사용자 교정 |
| 해결 가능성 | 원인 불명 | 방향은 있음 | 바로 적용할 diff 가 있음 |

영향 예시: 도구 호출이 한 번 실패했지만 같은 턴에 바로 복구했다면 1점, 다른 명령으로 우회하거나 재시도했다면 2점, 사용자가 결과를 고치게 했다면 3점이다.

해결 가능성 예시: 원인을 모르겠다면 1점, 어느 스킬을 고쳐야 할지는 알지만 문구는 정하지 못했다면 2점, SKILL.md 의 어느 줄을 어떻게 바꿀지 diff 로 쓸 수 있다면 3점이다.
